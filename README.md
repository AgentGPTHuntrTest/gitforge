A standalone GitHub-compatible git forge: one Node 22 process serving git smart HTTP (upload-pack v2 and v0, receive-pack v0), the REST v3 API, GraphQL v4 and MCP from its own in-memory store, with no UI, no dependencies and no git binary. Built for make.fun's "Build a GitHub-compatible git forge" bounty.

## Run it

```sh
node main.ts
```
